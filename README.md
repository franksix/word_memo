# App 简介

**【静心记单词】** 是一个**没有广告、不用联网、完全免费**的纯粹背单词小工具。

我们深知，记单词最怕被打扰。所以在这里，没有花里胡哨的社交排名，没有突然弹出的广告，也没有强制你每天打卡的压力。整个软件的界面采用了类似莫奈画作中睡莲池的柔和水绿色调，无论是在白天还是夜晚，都能让你静下心来，专注于眼前的单词。

**它有三个最大的特点：**
1. **完全是你的专属**：我们不提供固定的词库，你的词书由你自己做主。你可以自己一个一个敲进去，也可以把电脑上整理好的单词文件导进来。
2. **极度严格的测试**：只有“看着英文写中文”和“看着中文写英文”两种最硬核的模式。**答错了没法跳过，必须改对才能进入下一个单词**，专治“假努力”。
3. **数据永远属于你**：所有的东西都保存在你的手机里，你可以随时把它们导出成文件保存起来，不怕丢失。

# 新手使用指南

第一次打开 App 时，里面是空空的，跟着下面几步，马上就能开始：

### 1. 怎么把我的单词弄进去？
你有两种办法：

- **方法一：自己动手加（适合单词不多的情况）**
  点击屏幕右下角的 **“+” 号按钮**。给你的词书起个名字（比如“四级核心词”），然后就可以一行一行地把单词和它的意思敲进去了。想加几个就点一下“添加词条”，加完点“保存”就行。

- **方法二：把文件放进来（适合有现成单词表的情况）**
  如果你在电脑或手机里有整理好的单词表（不管是记事本、表格还是其他格式），点击右上角的 **“文件”图标**。
  它会让你选文件，选好之后，它会为你预览一下。你点一下屏幕上的 **“勾”**，这套词表就整整齐齐地存进你的手机里了。

### 2. 怎么开始背单词？
在你的词书列表里，点一下你想背的那本书，它前面会出现一个绿色的勾。
然后点击屏幕最下方的 **“▶ 播放”按钮**。
接着选一种练习方式：
- **翻译图标**：看英文，写中文。
- **拼写图标**：看中文，写英文。

### 3. 为什么我答错了，下一题的按钮不见了？
这是本软件最大的特色——**强制掌握**。
如果你答错了，屏幕上会出现一个红色的叉，底部的按钮会变成一个“刷新”的图标。这个时候，你需要修改你的答案，直到写对为止，底部的按钮才会变成“下一题”的箭头。别想蒙混过关哦！

### 4. 背完了怎么看结果？
当你背完这本书的最后一个单词，屏幕上会出现一个绿色的庆祝图标和数字。数字代表你这一轮背了多少个词。
你可以点左边的按钮**“再练一次”**，或者点右边的**房子图标**回到首页。

# 第三部分：日常进阶与管理

### 1. 怎么修改或删除单词？
在首页，找到你的词书，点击卡片上的 **“铅笔”图标**。
进去之后，你会看到所有的单词。你可以：
- 点单词旁边的 **“铅笔”** 修改它的意思。
- 点 **“垃圾桶”** 把它单独删掉。
- 点屏幕下方的 **“+”** 随时补录新词。

### 2. 怎么把单词分享给别人，或者备份？
还是在刚才的“铅笔”界面，点击右上角的 **“向下箭头”图标**。
软件会帮你把这本词书变成一个文件，你选一个地方保存下来。以后不管你是换手机，还是想把这本词书发给同学，只要把这个文件发过去，他们用右上角的“文件”图标导入，就能直接用了。

### 3. 如果我不想要这本词书了？
回到首页，在词书卡片的最右边点一下 **“垃圾桶”图标**，确认一下，它就被删除了。删掉的东西找不回来，操作前想清楚哦。

### 4. 关于白天和黑夜模式
本软件没有手动切换颜色的按钮，它会**跟着你手机的设置走**。你手机开了深色模式，它就会变成墨绿色的“夜色睡莲”风格；你手机用浅色模式，它就是清透的“晨雾”风格。这样用着最省心。
